# Ejemplos de marcas

Los archivos `public/assets/images/demo-brand-*.svg` son ilustraciones vectoriales originales creadas para la vista demo de este proyecto. Los nombres son ficticios y no identifican a proveedores de Ferretería Ayala. No deben utilizarse como logotipos reales ni publicarse como marcas de la ferretería. En el sitio publicado se utilizan exclusivamente las imágenes seleccionadas por administradores desde la biblioteca.
